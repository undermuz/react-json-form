## Overview

Dark Node.js–inspired landing for `@undermuz/react-json-form`: leaf-green accents, Open Sans, soft green glow. Offer is scheme-first forms (not page building): live JsonForm demo, nested widgets, and customization (themes / custom fields / JFL). Content is composed with `@undermuz/react-page-builder` blocks; Edit mode is DEV-only.

## Style Foundations

- **Visual style:** modern, minimal, spacious, dark-first (nodejs.org)
- **Typography scale:** desktop-first expressive scale
- **Typography fonts:** primary=Open Sans, display=Open Sans, mono=system mono
- **Typography weights:** 300, 400, 500, 600, 700, 800
- **Color palette:** Node green primary, soft green secondary, charcoal surface
- **Spacing scale:** comfortable density mode

## Colors

- **Primary (#5FA04E):** Node.js brand green for pills, links, and CTAs.
- **Secondary (#84BA64):** Lighter green for labels and glow accents.
- **Success (#5FA04E):** Checklist marks (same as primary).
- **Warning (#D97706):** Caution states.
- **Danger (#DC2626):** Destructive actions.
- **Surface (#0D1117):** Page background base (nodejs.org charcoal).
- **Surface elevated (#161B22):** Panels / code window.
- **Text (#FFFFFF):** Primary copy.
- **Text muted (#B9BBBE):** Supporting copy.
- **Border / glass:** Translucent white overlays for glass panels.
